# Brilliant-Monte-Carlo

**Disclaimer:** This repository contains a prototype notebook designed to teach the Monte Carlo method in an interactive, "Brilliant-style" format. It is a proof of concept and is not intended for official educational deployment.

---

In this notebook, you will find a concise explanation of the Monte Carlo method. It allows students to interactively adjust different variables within an "experiment" to build an intuitive understanding of how the method works.

This lesson was created over a weekend to demonstrate to the Brilliant hiring team how efficiently I can conceptualize and author original mathematics and statistics lessons using standard tools like Jupyter Notebooks.
